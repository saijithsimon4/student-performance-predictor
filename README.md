# 🎓 Student Performance Predictor (PCA + Machine Learning)

An interactive Machine Learning web application built with **Streamlit**, **scikit-learn**, and **matplotlib**.

## 🌟 Overview
This application uses **Principal Component Analysis (PCA)** for dimensionality reduction and **Logistic Regression** to predict student academic outcomes based on demographic and academic preparatory factors.

## 🚀 Live Demo
Deployable with 1-click on [Streamlit Community Cloud](https://streamlit.io/cloud).

## 🛠️ Tech Stack
- **Streamlit** (UI & interactive dashboard)
- **Scikit-Learn** (PCA dimensionality reduction & Logistic Regression classifier)
- **Pandas & NumPy** (Data processing & feature engineering)
- **Matplotlib** (2D PCA projection scatter visualization)

## 💻 Local Setup
1. Clone this repository:
   ```bash
   git clone <your-repo-url>
   cd <repo-folder>
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```
